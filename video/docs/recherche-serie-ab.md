# Recherche pour la série A/B « sans vendre » : hook, contexte, valeur, CTA, A/B organique, faits de la vidéo 1

Faite le 16 octobre 2026. Méthode : cinq axes cherchés en parallèle par un agent chacun (sources officielles des
plateformes d'abord, puis études avec échantillon, puis presse ; blogs seulement faute de mieux), puis un second agent
par axe chargé de **réfuter** les dix affirmations principales en rouvrant chaque source (verdict CONFIRMÉ / NUANCÉ /
RÉFUTÉ / INVÉRIFIABLE). Une affirmation sans URL ouverte n'est pas reprise. Les chiffres qui circulent sans source
primaire (« 63 % des vidéos accrochent en 3 s », « l'algorithme décide en 1,5 s »…) sont listés en « pas trouvé » et
**ne doivent pas être utilisés**.

Lecture : **F** = fait sourcé · **R** = recommandation d'une plateforme ou d'un expert · **D** = notre déduction ·
confiance haute / moyenne / basse · vérif = verdict du second agent.

**Contradictions avec notre pratique** : le contexte en bloc séparé (à fusionner dans le hook) ; la fenêtre « 3 s »
(c'est 2 s pour le lisible) ; la chute gardée pour la fin (une première récompense dans le hook) ; le CTA « suis pour la
suite » seul (à remplacer par une demande située) ; un démarrage voix seule ou avec fondu (musique à 0,0 s). Aucune
source ne contredit le hook « calcul à deux chiffres + objet qui contredit ».

**Pas trouvé** : benchmark organique de rétention à 3 s avec échantillon ; page primaire pour « 63 % / 71 % / 1,7 s /
1,5 s / 90 % » ; étude académique comparant des types de hooks à la rétention ; étude sur des comptes francophones
éducatifs ; zones sûres officielles en pixels pour l'organique ; dates des pages Creator Academy.
