# Prompt Suno : musique de MO5 (28 s, instrumental)

Mode **Custom**, **Instrumental** activé. Génère 4 à 6 versions, envoie-moi celles qui accrochent dès la première
seconde : je choisis le passage, je le cale sur la grille (120 BPM) et je place la coupure sur « 47 € ».

## Style (200 caractères max)

```
tense minimal hip-hop groove, 120 BPM, punchy kick, finger snaps, plucked bass, ticking hi-hats, playful dark synth hook, sudden stop, modern TikTok
```

## Structure

```
[Intro: hook from the first beat, no fade-in]
[Verse: groove with plucked bass and snaps, 3 bars]
[Breakdown: bass out, only ticking hi-hats and clock, 2 bars]
[Build: bass back, short riser]
[Stop: full silence, 1 beat]
[Outro: groove returns brighter, hook again, ends on the downbeat]
```
