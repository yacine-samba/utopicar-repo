# 100 carrousels débutants

Une seule cible : les débutants qui veulent se lancer en achat-revente. 10 séries de 10, toutes rendues dans
`video/renders/carousels-debutants/` (5 images, une planche et un post.txt par carrousel : titre, légende, 3 hashtags).

Chaque carrousel donne une raison de s'abonner (la dernière image annonce l'épisode suivant) et de commenter (une question précise).
Pas d'offre à la fin. Ordre de publication conseillé : `calendrier.csv` (un par jour, les séries en rotation, les épisodes dans l'ordre).
