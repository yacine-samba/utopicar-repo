# Prompt Suno : musique de MO4 (15 s, instrumental)

Dans Suno : mode **Custom**, **Instrumental** activé, et colle le style ci-dessous. Génère 4 à 6 versions, garde celle
dont l'impact tombe le plus net, puis envoie-la-moi : je la cale à l'image près sur le pivot (6,0 s), avec les bruitages
actuels.

## Style (champ « Style of Music », 200 caractères max)

```
dark minimal tech trap, 120 BPM, tense pulsing sub and ticking hi-hats, rising riser, hard 808 drop, then confident driving beat with bright synth pluck hook, punchy, modern ad
```

## Structure (champ « Lyrics », instrumental : balises seules)

```
[Intro: instant hook, muted synth stab + heartbeat kick, no fade-in]
[Build: ticking hi-hats, filtered pluck motif, tension rising, 4 bars]
[Riser: reverse cymbal, half-second silence]
[Drop: massive 808 hit, full drums, bright pluck hook]
[Outro: driving groove, hook motif repeats, clean ending on the beat]
```

## Ce que la musique doit faire, calé sur l'image

| Temps | Image | Musique |
|---|---|---|
| 0 s | le point éclate, l'annonce jaillit | un son qui accroche dès la première image, sans fondu |
| 0–6 s | « Bonne affaire ou piège ? », collage, 4 vérifications | tension qui monte, motif court reconnaissable |
| 5,5–6 s | dernière coche | montée, puis un silence d'une demi-seconde |
| 6,0 s | **pivot** : la fiche se révèle | **drop** : grosse frappe |
| 6–15 s | verdict, prix à proposer, logo, bouton | élan, rythme franc, le motif revient |

Tempo : 120 BPM, soit un temps toutes les 0,5 s. Les coches tombent sur les temps.
